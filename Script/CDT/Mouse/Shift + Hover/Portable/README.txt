===================================================
   Shift+Hover MM-to-Imperial Converter - PORTABLE
===================================================

QUICK START:
1. Extract this entire folder anywhere on your computer
2. Double-click "ShiftHoverConverter.exe"
3. Look for the cyan "AU" system tray icon (bottom-right)

USAGE:
- Ctrl+Shift + Hover mouse = Shows instant mm-to-imperial tooltip
- Ctrl+Alt+H = Open conversion history window
- Double-click any history entry = Batch replace that value in P2.CDT
- Right-click history entry = Restore original value
- Ctrl+Alt+T = Toggle tooltip on/off
- Right-click tray icon = Exit

FEATURES:
✓ OCR captures mm values from any window
✓ Real-time imperial conversion tooltips
✓ Color-coded history (green=original, red=modified)
✓ Batch find/replace in CDT files
✓ Restore original values anytime
✓ Works with Randek Viewer and CAD software

PORTABLE:
- No installation required
- Tesseract OCR included (no separate install needed)
- Copy to USB drive or network share
- Works on any Windows PC

REQUIREMENTS:
- Windows 10/11
- Python libraries (bundled in EXE)
- CDT files (P2.CDT or P1.CDT in workspace)

NOTES:
- Randek Viewer doesn't auto-refresh - close and reopen file to see changes
- Values are replaced as whole numbers (6096.0 → 6096)
- Uses regex word boundaries for accurate replacement
